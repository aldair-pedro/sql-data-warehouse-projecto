# sql-data-warehouse-projeto
Bem-vindo ao **Data Warehouse e analítico projeto** repositório
Esse projeto demonstra uma abrangente **Data warehouse** e soluções analíticas,desde a construção de um data warehouse até criar insights.Designado como um portfolio com boas práticas de analista
-----
## Requisitos do projeto
### Construindo um Data Warehouse(Eng.Dados)
#### Objectivo
Desenvolver um data warehouse moderno usando Postgre SQL para consolidar dados de vendas,permitindo um relatório analíticoe informar decisões.
#### Especificações
- **Dados**: Importar dados de duas fontes (ERP e CRM) fornecidos como ficheiros CSV.
- **Qualidade dos dados**: Limpeza e resolver problemas de qualidade dos dados para a análise.
- **Integração**: Combinar as duas fontes em uma,para facilitar as consultas de análise.
- **Escopo**: Focar no ultimo dataset apenas,historização dos dados não é obrigatória.
- **Documentação**: Fornecer uma documentação clara dos dados para apoiar ambas áreas de negocio e grupo de analistas.

### BI: Análises  e Relatórios (Análise de dados)
#### Objetivos
Desenvolver analises baseadas em SQL para entregar  insights detalhados de:
- **Comportamento do cliente**
- **desempenho de produtos**
- **Tendências nas vendas**
